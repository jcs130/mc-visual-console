# 地形保留、全员选人和紧凑观战 HUD

2026-11-01。源码、构建、离线检查、加载、实景分别留证。

## 两个现场缺陷

原生 0.1.17 把 OrthoCamera 的全画面斜近裁面当成了“房间剖视”。裁面只按人物身体边界计算，既没有局部遮挡物掩码，也没有地板边界；树冠/洞顶满足头顶射线条件时同样会触发。前景地表一旦被裁掉，后面的地下区域和空白就露出来。可见性射线又从裁后区域开始计算，造成虚假的“人物无遮挡”。

选人原来先从最新物理事件或发言提出一个人，再用当前画面判断 keep/机位。maxDwell 只是已有竞争者的分数条件，并没有真的触发全员重新比较；持续发言的人可能一直占镜。正交投影偏好还额外拦截跨主体切换。上述问题不能用模型调用计数或一次渲染成功掩盖。

## 0.1.18 的遮挡边界

OrthoCamera 的 min_distance 固定为原始 -32，停止把人物边界作为全世界裁切面。状态明确声明 worldCutawaySupported=false、roomClip=false、occlusionHandling=rotate_or_perspective。原生正交、姿态、缩放、平滑仍可用；原生模组没有局部淡出能力，就不伪装成已经实现局部剖切。

可见性探针使用完整 32 格视线，保留墙壁、树冠、地面等真实遮挡；优先寻找可见方位，仍遮挡就回到同主体透视/近墙第一人称。脚下四处真实支撑射线单独验证 floorSafe；头顶有覆盖不再自动等于“地板安全”。房间和多层建筑不能靠全局斜切显示内部。

纯几何回归复现旧裁面会删掉前景地表，确认同一批地表点在未裁世界深度内保留；最终像素仍须现场检查，不以射线分数替代完整模型的像素可见率。

## 谁应当出镜

SceneSelector 只消费宿主注入的真实事件及原生位置/画面回执。姓名名单是宿主配置；可用性来自当次原生玩家身份，不因长期没镜头就猜测一个玩家在线。

1. 真实战斗优先；当前主体有八秒内新战斗证据时保护本段。其次为成功操作/实际移动，普通发言优先级较低，消息量不会累加成无限权重。
2. 只有实际渲染画面推进每名玩家的累计出镜、最近出镜和访问次数。重复帧不重复计数，未观察到的长间隔不算有效出镜。缺位置保持 unknown，不冒充静止。
3. 一般主体驻留至少 30 秒；确认静止后可在 12 秒让位给新进展。普通主体在 90 秒发起全员重新评估，原请求终态、安全门及持续战斗仍须满足。初次没有事件但有明确在线名单时，先观察一位可用玩家，避免认证成功后永久无镜头。
4. 最近活动、等待时间和累计出镜进入同一主体候选包。没有画面的其他人不被标成不可用，也不编造他们的预览。
5. 两个话多的人不能靠每次提前交换镜头绕过公平性。未被观察的玩家等待达到 maxDwell×max(2,可用人数−1) 后，在下一次满足最低驻留的非战斗时机进入必须覆盖的候选池。只有一个合法人选就直接用规则，不假装进行了模型推理。
6. 需要模型时发出独立的 subject 问题，比较所有当次合法主体。普通竞争可以 keep；覆盖期限的候选只包含合格的其他主体。模型概率必须覆盖整个候选集合，校验后使用；不明确时按同一候选池的规则回退。概率是分类偏好，不是实景成功率。
7. 换人先用真实第一人称建立现场事实，再根据该人的几何和截图决定正交、跟随或其他构图。选人不再让当前画面“看起来不错”的机位保持建议永久挡住其他人。

主体判断和同主体机位判断分离：前者用全员事实和覆盖统计，后者用当前人物的真实画面。普通行进的位置变化不会让一个仍然新鲜的跨主体判断作废；新目标 UUID、世界、原请求或手动状态改变时仍取消。

## 节奏与预算

同人机位至少 12 秒；编辑变更最多四次/分钟，换主体最多两次/分钟。投影 45 秒冷却只约束同主体构图，不锁住当前人物。返场通常冷却 60 秒；已确认静止的巡看镜头遇到离开后新发生的真实操作/移动/战斗，15 秒后可以让位，普通发言不能使用此例外。

总模型批次仍最多六次/分钟、单批、15 秒超时、无自动重试。机位判断最多占四次，给主体判断保留预算。当前一张图供三题机位判断共享编码；主体判断只把当前截图当作当前人的证据。日志只保存阶段、错误码、请求/会话/模型 ID、候选数和统计；不保存提示、截图或回答正文。

状态公开 subjectCandidates 和 subjectPolicy，可查看活动类型、源时间、静止/未知、等待、出镜时长、当次期限；实际切换仍用稳定相机请求与原生渲染回执确认。主体建议不是目标完成。

## HUD 0.1.4

默认两行：姓名/职业等级、生命/魔力。低饥饿增加一行警示。宽度随文本收缩，最大 170 个 GUI 单位，背景透明度降低；默认不铺满整个右上角。

F9 循环：紧凑摘要 → 完整概览 → 技能 → 背包 → 原始字段 → 隐藏；F10 翻页。原始数值、经验、经济、完整物品和未知值保留，未同步不编造。E 的原生只读背包不变。hud 诊断记录实际绘制矩形、行数及画布大小，方便测量占屏面积；渲染时继续核对目标绑定，切人不能沿用上一人的数据。

共享公开入口 scene-selection 和 native-director-policy 支持独立宿主。模型、认证、人格、长期记忆由宿主提供，本模块不启动游戏 Agent 或隐藏模型循环。npm 发布和现场长期效果另行记录。
