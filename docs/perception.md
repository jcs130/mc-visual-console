# 场景小地图与可见性

小地图复用真实场景渲染，坐标沿用 Minecraft XYZ。实体位置不加半格；方块标记使用方块中心。中文标签通过数量预算、聚类和布局避让减少遮盖，周边画面不变暗。

- 和平、探索、战斗模式只改变信息筛选与显示，不控制 Agent 行为或改写宿主目标。
- 当前地形必须通过本地视线与碰撞检查。未观察区域保持未知；亲眼见过而目前遮挡的地形保留历史像素，并用纹理标为“未更新”。历史不跨连接或维度混用。
- 地下或树冠下自动采用当前高度剖层（脚格以下 8 格至以上 1.25 格），画面裁剪与可见面采样使用相同高度范围。切到实体方块内部的列保持未知，仍按本人视线遮挡；剖层不是透视，也不是可达性证明。不同高度层和地表的历史像素不混用。
- 动态实体必须当前可见；在线、邻近或原始区块已加载不等于被看见，也不证明队友关系。
- 听觉消费宿主声音线索，只显示方位、粗距离、类别和时间，不显示声音精确坐标。
- 预测区基于可见实体的短时运动趋势，注明预测与时间。攻击范围、视野范围和概率没有证据时为未知，不用物种名称猜成服务端事实。
- 总览截图必须提供观察范围遮罩。特殊探测技能由服务器适配层提供带时间、连接、维度及回执来源的独立证据；施法被受理不等于探测结果。

此模块拥有画面和观察缓存，不拥有模型供应商、凭据、人格、长期记忆或游戏连接。
