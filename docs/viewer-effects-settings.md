# 可视化特效设置

原版网页画面的「画质与特效」菜单提供独立开关：

- 粒子与受击特效：服务器粒子及受击、暴击、烟花等粒子。
- 声音波纹、光环与技能提示：声音的视觉波纹、状态环和明确标注为聊天推断的技能提示。音频仍由音效开关控制。
- 雨雪画面：关闭实际 rain 渲染模块；保留收到的天气状态。
- 动态人物阴影：允许或禁止阴影；开启还需电影风格与精细画质。

开关即时生效，不需要重新连接游戏。关闭时释放已有特效的几何体和材质，并停止创建对应特效；全部关闭且无提示时取消特效动画帧。生命值、状态图标、游戏感知与动作保持独立。设置保存在当前浏览器来源的 localStorage；换浏览器或更换网页来源后需要重新设置。OBS/拍照页面沿用已保存设置，设置菜单在普通游戏画面中打开。

旧设置文件无需迁移：缺少字段时保持原有开启行为，明确的 false 才关闭。该菜单属于通用原版现代渲染器，不改变原生模组渲染器的特效契约。消费方须按各自原版版本和 preset 重建浏览器 bundle，不能只更新连接台文件。
