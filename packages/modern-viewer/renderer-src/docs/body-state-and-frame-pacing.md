# 倒地状态、连续移动与音效核验

## 服务端身体状态

宿主可在本人实体快照中附带 `bodyState: { source: 'server', pose: 'standing' | 'downed', canAct: boolean }`。服务器玩法扩展负责解释倒地、救援协议；渲染器不解析聊天文字，不根据低血量或静止推测倒地。

`downed` 使用原角色几何和贴图呈现卧倒姿态，禁止挥击、使用物品和行走叠加。没有新位置包、速度采样过期或经过很长时间都不会自行站起。明确恢复、本人身份或连接代次变化才清除旧状态。普通 Minecraft 角色与 YSM 都支持这一通用呈现；它不是对某个服务器 Java 救援动画的像素复刻。服装、尾巴的原静态形状保持，完整原生动画一致性仍未核验。

## 移动与帧时序

- 原位置缓动每收到实体包都会从当时的显示位置重新开始。现在用最多 32 个时间采样，延后 100 毫秒插值，不外推未知位置；瞬移、超过 4 格跳变和长包间隔重置。装备或姿态的重复包不会重开追赶曲线。
- 60 帧限制使用浏览器传入的 RAF 时间及有界相位容差。旧逻辑用回调执行时间并严格比较 16.666… 毫秒，正常显示器的时间量化会误丢整帧。120/144/240 Hz 显示器仍受帧率限制。
- 合并同一可动画祖先下的静态 YSM 几何，保留可动画骨骼、手部定位、原顶点、法线和 UV；嵌套非均匀缩放不使用矩阵逆运算。较重的统计和 DOM 更新限制为每 250 毫秒一次。

不要把 RAF 回调次数当成实际渲染帧率。比较时同时记录渲染计数、帧间隔、实体原始采样与显示位置、场景及视口。离线插值和限帧测试不能证明所有真实场景持续 60 FPS。

## 音效

原版声音走真实服务器事件、原 sounds.json 与原 OGG。事件名允许有效命名空间和路径；自定义事件缺少资源时明确记录，不改成另一种声音。`cortiWorldAudio.state().audioEvidence` 提供请求、开始播放、失败、缺失与类别计数，缺失事件列表有界。资源显式配置的空音轨属于静音，不算缺失。

资源完整、浏览器解码成功、开始播放和人耳听见是不同验收层次。测试覆盖自定义事件名、未知事件与原静音配置；需要真实场景分别验证环境、生物、攻击、方块、物品和自定义玩法事件。浏览器自动播放许可和用户音量保持原设置。

## 本轮证据边界

2026-10-14 全套渲染测试 727 项：715 通过，12 项因原生资产条件跳过。真实 Cormy 模型在离线浏览器对照页已显示站立与卧倒。1.20.6 声音清单 1,604 个事件、3,681 个原 OGG 经来源哈希校验，缺失为零；实景一段采样有 17 次成功开始播放、零失败和零缺失。尚不能据此称所有自定义音效或硬件听感均已验收。最终限帧修订的实景复测受游戏连接超时阻断，后续需继续验证。
