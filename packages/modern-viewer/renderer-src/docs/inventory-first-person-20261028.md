# First-person cave visibility and original armor

The display-camera section guard now runs for first person as well as observer cameras. The pinned section graph can choose an unrelated sky seed when the eye enters an empty/unmeshed section, dropping already received cave walls until a later quality sample. Its synchronous guard retains received draw spans when connectivity is unknown, seeds from the rendered eye and invalidates the graph before returning to a received section. It does not change chunks, registry states, collision or Agent perception.

Inventory fallback skins pass through the same skinview normalization as world skins, including legacy 64×32 PNGs. Original source pixels are retained; mirrored geometry/materials stay shared while preview skeletons and normalized fallback textures have private disposal. Full selected custom actors retain their authored pose; classic sibling armor is hidden and restored together with the replaced native skin, with held items retained.

The portable builder records original armor PNG paths, sizes and SHA256 values from the exact asset version. Both legacy `models/armor` and modern `entity/equipment/humanoid{,_leggings}` directories feed the existing renderer contract; modern copper armor no longer shows a bare/different body while its inventory icons are present. Original pack overrides keep precedence. No Java-version whitelist chooses armor geometry or blocks login. Compatible particle/map asset schema uses exact manifest/client matching rather than a 1.20.6/1.21.1 whitelist.

Acceptance: Node tests exercise the actual pinned occlusion graph, private skeleton/resource ownership, legacy skin pixels, texture aliases and path/version rejection. Isolated 1.21.1 cave/leather and 1.21.11 copper scenes use real versioned registries, mesher and original PNGs in browser WebGL, with no Minecraft connections or model calls. These procedural QA scenes are not live gameplay or complete Java pixel parity. The reporter identified the skin as a vanilla server skin; its exact original PNG was not provided, so the attachment itself is not a claimed pixel-for-pixel reproduction.

Host consumers must freeze this shared revision, rebuild every shipped asset version and update their package pin. Source publication does not reload existing users, game servers or Cortico. Private screenshots, generated assets and original client JARs stay outside Git.
