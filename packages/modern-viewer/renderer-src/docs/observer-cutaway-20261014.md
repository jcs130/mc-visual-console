# 观战切面与渲染预算

## 实际问题

第三人称镜头进入岩层时，关闭切面仍会看到远处洞穴。区块网格只生成暴露面，没有实心岩层内部表面；当时观战模式还关闭了原生区块连通性剔除。另有天空无深度材质被切面克隆、改变绘制顺序的问题。

## 通用修复

- 原生区块连通性按观战镜头计算；切面打开时同时保留人物所在房间。图结果按区块/镜头所在区域缓存，不逐帧重算。未知区块保持未知，加载后重算。
- 切面只沿已测得的连通地板及前景视线打开，保留脚下支撑；完整不透明方块使用已解析的原始顶面 UV 封闭附近 32 格内的实体内部切口。封口合并为一个网格，只在地形或镜头格位置变化时重建。
- 封口只支持已验证完整立方体、可用原始模型和 UV；未知、流体、非完整模型明确计入 unavailable，不用简化方块替代。该几何仅用于观战展示，不进入 Agent 感知、碰撞或地图事实。大范围和特殊模型仍需独立验收。
- 天空和无深度背景不参与切面；第一人称拍照不创建封口。浮动原点逐帧更新位置；换维度或资源重载会丢弃旧缓存。
- 小地图可见性/历史地形的射线计算移入空闲时段，每次 1 毫秒预算。动作相位在走、跑、潜行之间连续，基础姿态渐变后再叠加挥手和头部动作。

## 验证边界

742 项渲染工具测试：730 通过，12 项既有资产缺失跳过。实景中 20 秒、1199 帧样本为 59.93 FPS，p95 16.8ms、最大 33.4ms；此前移动窗口 58.90 FPS。不是所有设备/场景的 60 FPS 保证。现场区块剔除、人物及近处地形已核验；岩层内部穿透有同镜头诊断夹具对照，下界原现场修复后复验仍待自然返回。

维护者实现；不是 Agent 自主学习成果。源码、浏览器资源热更新、游戏核心加载分别记录，不需要为网页资源中断游戏。
