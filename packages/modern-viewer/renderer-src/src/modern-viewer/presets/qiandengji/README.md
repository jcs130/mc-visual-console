# 千灯纪画面预设

这里放服务端命名角色的精确身份映射、美术档案、肖像路径和网页本地剧情文案。匹配需要服务端给出的角色名和身份键；没有匹配时渲染器使用原版实体模型。预设不会向服务端发命令，也不会替代 Mineflayer 接收到的区块、实体、装备、背包和生命状态。

技能、魔力、保护区、试炼任务和 `/mycli` 的行动规则由独立的 `cortico-world-qiandengji` 维护。服务端结构化状态经 Cortico 的 viewer 桥接展示；本预设只负责浏览器表现。

根目录同名模块目前是兼容导出，保证既有构建和测试继续工作。将来如果要做完全不包含此预设的通用 bundle，可把这些兼容导出替换为可配置的预设入口。
